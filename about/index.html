このサイトについて

「AKB48 名鑑（β版）」は、AKB48のファンが個人で作っている非公式のデータベースです。AKB48、運営会社、公式サイトとは関係ありません。広告は載せていません。

方針

  • 誰でも確かめられる、客観的な記録だけを載せます(在籍、選抜、センター、売上、総選挙、劇場公演など)。
  • 本名、ロゴ、歌詞は載せません。メンバーの写真も載せず、公式サイトへのリンクで案内します。
  • MVは、AKB48公式YouTubeチャンネルの動画を、YouTubeの埋め込み機能とサムネイル画像で紹介しています。動画も画像もYouTubeから直接表示していて、このサイトには保存していません。
  • 私生活、うわさ、評判、休演の理由は扱いません。
  • すべてのデータに出典を付けます。出典は各ページの下にあります。
  • SNSの投稿を自動で集めることはしません。

アクセスの集計

このサイトは、どのページがよく見られているかを知るために Cloudflare Web Analytics を使っています。Cookie は使わず、個人を特定する情報は集めていません。

このブラウザからのアクセスを集計に入れたくない場合は、下のボタンを押してください(このブラウザだけに記録されます)。

誤りの報告

データの間違いや古い情報を見つけたら、教えてください。確かめたうえで直します。

誤りを報告する(Googleフォーム) ↗

名前やメールアドレスの入力は必要ありません。どのページの、どこが、どう違うかを書いてください。出典(公式サイトや記事のURL)があると、早く直せます。

データの決め方

  • 「選抜」は、シングルの表題曲の歌唱メンバーに名前があるかで判断しています。カップリング曲やユニット曲は数えていません。
  • 選抜回数は、AKB48に在籍していた間の回数です。移籍先のグループのメンバーとしての選抜や、卒業後のOG参加は、色を変えて別に表示し、回数には入れていません。
  • 発売前のシングルも、選抜が公式に発表された時点で回数に数えています。
  • フロント(1列目)は、立ち位置の資料が確かな17作(31st、52nd〜68th)だけで数えています。
  • 加入日はお披露目の日、退団日は最終の在籍日を基本にしています。2回在籍した人は、期間ごとに分けて扱います。
  • 売上はオリコンの数字です。年間ランキング時点の累計は、その後の売上を含みません。
  • 時期の名前(創成期、黄金期など)は、売上と在籍人数の数字をもとに、このサイトが付けたものです。

更新

公式サイトのスケジュール(劇場公演、出演予定)は、1日に数回、自動で取り込んでいます。そのほかのデータは、公式発表を確かめて手作業で更新しています。このページの最終更新: 2026-11-14

あなたの記録の扱い

推しの登録と観覧ノートは、あなたのブラウザの中にだけ保存されます。このサイトのサーバーには送られません。「あなたの日のAKB48」に入れた日付は、保存も送信もしません。

プライバシーについて

  • このサイトは、会員登録やログインの仕組みを持たず、名前やメールアドレスなどの個人情報を集めていません。
  • 推しの登録・観覧ノートは、あなたのブラウザの中(localStorage)にだけ保存されます。ブラウザのサイトデータを消すと消えます。
  • 文字の表示に Google Fonts を使っています。表示のため、あなたのブラウザが Google のサーバーに接続します。
  • 誤りの報告は Google フォームで受け付けています。フォームでは名前やメールアドレスを集めていません。入力した内容は Google のサービス上に保存されます。

掲載内容の削除・訂正の依頼

ご本人や関係者の方から、掲載内容の削除・訂正のご依頼があれば、上の報告フォームからお知らせください。内容を確かめたうえで、できるだけ早く対応します。

アクセス解析

どのページがどれくらい見られているかを知るために、Cloudflare Web Analytics を使っています。Cookieを使わず、一人ひとりを追いかけない仕組みで、集めるのはページごとの閲覧数などの全体の数字だけです。
